# Contributing

Contributions that keep `skillsrc` focused on reproducible dependency management for `.agents/skills` are welcome.

Before opening a pull request:

1. Open an issue for substantial behavior or design changes.
2. Keep the change narrow and include tests for observable behavior.
3. Run `go test ./...` and `go vet ./...`.
4. Explain the user-facing problem and any safety implications in the pull request.

Multi-agent installation targets and compatibility layers are outside the project's scope. Just create your own tooling.
